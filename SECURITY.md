# Security Policy

## Supported Versions

Fixes go into the latest release only. The library is pre-1.0, and older versions are not patched.

| Version | Supported |
| ------- | --------- |
| 0.x (latest minor) | yes |
| earlier than the latest minor | no, upgrade to the latest release |

## Reporting a Vulnerability

Please do not open a public GitHub issue for a security vulnerability.

Report it privately through GitHub:
https://github.com/scigolib/netcdf/security/advisories/new

Please include the affected version, a minimal reproduction (the smallest file that triggers the
problem), and the impact you see.

- Initial response: within 72 hours.
- Fix and disclosure: coordinated with the reporter; credit is given unless you prefer otherwise.
